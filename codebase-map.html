Pico2Seq — interactive codebase map

A 4-voice polymetric step sequencer and synth for the Raspberry Pi Pico 2 (RP2350). It is an Arduino sketch, not a desktop app: there is no main(), and most code only makes sense in terms of the two cores — Core 0 touches the player and keeps time, Core 1 makes sound. This map is a way in: every box, arrow and claim points at a real line in this repository.

02 The two cores, side by side

This split is the single most important thing to know before changing anything. The audio core is real-time: nothing there may block, allocate, or wait on a display. The control core may be slow, but it must never stall for long — a watchdog reboots it after two seconds.

07 Codebase honesty: what is proven, and what is not

A host test proves logic. It cannot prove I2C timing, PIO/DMA behaviour, or that the board sounds good. This section separates the two, so nobody mistakes a green test run for a working instrument.

Hardware-bound glue — not host-tested by design

Compiled by the Arduino build only. Validated by bench work and the serial diagnostics, never by CTest.

Host-tested portable code

Compiled and run on the dev machine with Catch2 v3.5.2, using header stubs so no hardware is needed.
