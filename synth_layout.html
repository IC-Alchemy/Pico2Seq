Pico2Seq — Interactive Panel Explorer

4-voice polymetric step sequencer / synthesizer on Raspberry Pi Pico 2 (RP2350). Click any control on the panel to toggle it and read what it does. Space = play/stop · Shift+click a parameter button = latch.

Transport

uClock ticks 16th notes; each voice's Gate track length defines its pattern length, so voices can polymeter against each other.

Selected voice

Boot presets: V1 Square · V2 Bass · V3 Digital · V4 Percussion. On hardware, presets are picked on pads 8–22 in Settings (hold Play).
