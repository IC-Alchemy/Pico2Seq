01
Five-minute ignition procedure

Quick Start

Do this first. The machine boots already running at 90 BPM. Your job is to give the clock something worth saying.

1 • POWER + AUDIO

Connect the I2S DAC/audio output to a mixer or amplifier, then power the Pico 2 over USB. USB is currently power + TinyUSB CDC serial diagnostics, not MIDI.

2 • FIND A VOICE

Press V1–V4. Factory startup assignments are V1 Square, V2 Bass, V3 Digital, V4 Percussion.

3 • MAKE GATES

Tap the 32 touch pads. Rows 1–2 are the low voice of the selected pair; rows 3–4 are the high voice. Lit pads are active gates.

4 • SHAPE IT

Put GP7 in PARAM mode. The four faders address Filter, Attack, Decay and Velocity on standard voices. The magnetic encoder starts on Velocity.

5 • BREAK THE GRID

Hold a parameter button and choose a pad length. Give Filter 5 steps against a 16-step Gate track. Now the phrase evolves instead of merely looping.

6 • ADD POCKET

Flip to UTILITY. Fader 1 is 45–200 BPM. Fader 2 supplies continuous swing. Utility button 4 cycles the 16 groove templates.

Fastest satisfying first patch: select V2 Bass, light steps 1, 4, 7, 11 and 15; PARAM mode, lower Filter, shorten Decay; UTILITY mode, choose Swing (57%); then give Filter a 5-step track. Five minutes, one small rhythmic machine with a long memory.

Long gestures

Long-press a pad to enter Step Edit. Long-press Play to open/close Settings without stopping playback. Hold Encoder Target to enter Gate Sequence Length mode, then touch a pad to set the selected voice's Gate track length. Long-hold Randomize resets rather than randomizes.

03
Time as a set of gears

Polymetric Sequencing

A step is not one row of data. Pico2Seq gives each parameter its own loop length. The result is closer to a box of meshing gears than a spreadsheet.

One voice, nine clocks

NOTE
7 steps→VELOCITY
5 steps→FILTER
11 steps→GATE
16 steps

The tracks advance from the same 16th-note clock but wrap independently. Gate length defines the visible/master pattern length for that voice; the other lanes orbit through it.

TrackMeaningUseful trick
NoteScale-degree pitch laneUse a 7-step pitch phrase against 16 gates.
VelocityAmplitude, or an engine-specific lane on some presets5-step accents keep migrating.
FilterCutoff on standard voices; macro on specialized enginesPrime-ish lengths make slow timbral cycles.
Attack / DecayEnvelope timing on standard voices; macro lanes on specialized enginesShort repeating articulation against longer notes.
Octave−1 / 0 / +1 octaveA 3-step octave lane creates instant register motion.
GateLengthFraction of a step heldShort gates for clockwork, long gates for legato.
GateNote trigger and voice pattern lengthSet 13 or 15 steps for voice-level polymeter.
SlidePortamento into a step, no envelope retriggerUse sparingly before a long gate for liquid motion.
Pitch is gate-protected. Note edits only land on steps whose Gate is on. This is intentional: silent steps do not accumulate invisible pitch edits.

Groove library

Sixteen 480-PPQN templates are built in: No Shuffle, Teeny Swing, Lil' Swing (53%), Neg' Swing (53%), CornBread, Swing 55/56/57/60%, Big Swang 60%, Phatty Swang, Big Swang 62%, Humanize 1, Humanize 2, Hip-Hop and Funk Groove. Utility Fader 2 can instead impose a continuous odd-step delay.

Scale library

13 tables: Ionian Major, Dorian, Phrygian, Lydian, Mixolydian, Aeolian Minor, Locrian, Pentatonic Minor, Phrygian Dominant, Lydian Dominant, Harmonic Minor, Wholetone and Chromatic.

05
Hands on, hands off

Performance Control

Magnetic encoder

TMAG5273A rotation with velocity-sensitive acceleration. Slow movement gives fine control; faster turns sweep larger ranges. The default target is Velocity. Utility Encoder cycles the target.

Distance sensor

VL53L1X time-of-flight control, effective performance range documented around 74–1400 mm. Hold or latch a parameter and move your hand to write live motion.

Faders

Four 12-bit channels. In PARAM they become direct musical gesture; in UTILITY they become transport/groove/timing controls.

OLED + LEDs

The 128×64 SH1106G prioritizes transient mode/settings/edit/status views. The 8×4 RGB grid mirrors pad geometry and carries gate, playhead and polymetric feedback.

Three performance recipes

THE MOVING FILTER

Latch Filter with Shift+Filter. Play a bass pattern. Move your hand over the TOF sensor to record a cutoff contour. Then shorten the Filter track to 5 or 7 steps so the recorded shape rotates through the gate phrase.

THE STRING MACHINE

Load WgShimmer. The familiar Filter/Attack/Decay controls become Bright/Pick/T60. Give Bright 11 steps, T60 3 steps, and a 15-step Gate pattern. The sound changes structure without adding another LFO.

THE RECIPE VOICE

Load Prism or FMGlass. Watch the OLED legends rather than trusting the panel nouns. Sequence Focus/Spread/Drift or Index/Ratio/Feedback independently. This is where Pico2Seq stops behaving like a conventional subtractive groovebox.

06
Under the wooden floorboards

Signal + Architecture

The RP2350 is split asymmetrically. Core 0 thinks about time and people. Core 1 thinks about audio and refuses distractions.

Audio road

4 SEQUENCERS→VOICE CONFIG→OSC / ENGINE→FILTER / MACROS→VCA / CHARACTER→VOICE SUM→I2S 48 kHz

CORE 0

Clock event processing, PPQN/gate timing, 32-pad MPR121 scan, Alchemy tile polling, GP7 mode strap, TMAG5273, VL53L1X, OLED, LEDs and CDC diagnostics.

CORE 1

AudioEngine::renderNextBuffer(). It takes an I2S buffer, processes/sums the four voices, converts to PCM16 and returns the buffer. The design keeps blocking I2C and UI work away from audio.

Firmware bench notes

Build + Flash

Arduino IDE

  1. Clone the repository with submodules.
  2. Open Pico2Seq.ino.
  3. Select Raspberry Pi Pico 2 / RP2350.
  4. Use the Adafruit TinyUSB stack.
  5. Install the library versions listed in the repository README.
  6. Compile and flash. Open the CDC serial console at 115200 for startup diagnostics.
git clone --recurse-submodules https://github.com/IC-Alchemy/Pico2Seq.git
cd Pico2Seq

The command-line Windows build has an important wrinkle: Arduino CLI recursively compiles sources below the sketch's src tree, including submodule examples. The repository README contains the verified staging script that copies the tree to a temporary correctly named sketch while omitting examples directories.

Host tests

cmake -B build_test -DCMAKE_BUILD_TYPE=Debug
cmake --build build_test --parallel
ctest --test-dir build_test/tests --output-on-failure

Clock-race regressions also have a dedicated pico2seq_clock_tests target. The current branch includes the PPQN lost-tick handoff fix merged on 2026-09-08.

When the lamps stare back

Troubleshooting

SymptomLikely place to look
No sound but LEDs moveCheck I2S DAC power and GP10/11/12 wiring, then verify the audio codec/amplifier path. The sequencer can run perfectly while the external DAC path is silent.
Touch grid dead at bootMPR121 is mandatory in the current startup path. Verify 0x5A on main I2C, wiring and touch/release thresholds.
Faders / function buttons deadCheck the Alchemy tile scan report in serial. SliderModule and ButtonModule8 live on Wire1 at 100 kHz; the firmware prints explicit “tile missing” diagnostics.
OLED stale or blankCheck 0x3C and main I2C. The current code uses a shadow-buffer compare to avoid redundant full-frame pushes.
Encoder or hand control absentCheck TMAG5273A 0x35 and VL53L1X 0x29. Startup reports success/failure for both.
Delay button does nothingExpected in the default build. Delay is compiled out.
USB MIDI does nothingExpected. USB MIDI transmission was removed. USB currently carries power and CDC serial only.
Panel says Filter but OLED says Index / Bright / FocusExpected on specialized presets. Those sequencer lanes are deliberately rebound to engine macros.
Documentation rule: this manual follows the current Working-Audio implementation where it conflicts with older prose. In particular: 21 presets, USB MIDI removed, delay disabled by default, main I2C fast-mode work merged, and the top-level sketch refactored down to four Arduino entry points delegating into Application and AudioEngine.

Operator's glossary

BANK

One 16-pad half of the 32-pad grid.

GATE

Whether a step triggers, and the track whose length defines the voice pattern.

LATCH

Shift+parameter keeps that parameter armed without holding the button.

POLYMETER

Independent track lengths that wrap at different times.

RECIPE

A digital voice engine whose central sequencer lanes map to engine-specific macros.

STEP EDIT

Long-press a pad to focus editing on that step.
