1Overview & Panel

Pico2Seq is a 4-voice polyphonic step sequencer and synthesizer built around a Raspberry Pi Pico 2 (RP2350) in a laser-cut wooden chassis. Each of the four synthesizer voices is driven by its own independent step sequencer, and every sound parameter — pitch, velocity, filter, envelopes, octave, gate, slide — can run on its own step length, so patterns drift against each other polymetrically instead of staying locked in lockstep. One button combination turns the whole instrument into a chord arpeggiator.

2Quick Start

  1. Connect & power. Stereo Out to a mixer/amp (or headphones via an amp), then plug in USB. The OLED runs its startup animation; the serial console (115200) prints boot diagnostics.
  2. The transport starts running by default at 90 BPM — nothing plays yet because every step starts with its gate off.
  3. Factory boot sounds: Voice 1 = Square, Voice 2 = Bass, Voice 3 = Digital, Voice 4 = Percussion.
  4. Select a voice — press V1–V4 next to the faders.
  5. Program a pattern — tap pads in the bank rows for that voice (§3). Lit pads are active steps; the LED playhead shows where you are.
  6. Shape the sound — turn the magnetic encoder (Velocity target by default; cycle targets with Utility button 6). To shape one step's envelope, long-press its pad and use faders 1–4.
  7. Try polymeter — hold a parameter button (e.g. Filter) and tap pad 5: the Filter track is now 5 steps long and cycles against the 16-step Gate track.
  8. Change key feel — hold Shift + tap V3 to cycle the 13 scales.
  9. Groove & delay — fader 1 sets tempo; Utility button 4 cycles the swing templates; fader 2 is the master delay mix (Shift + fader 2 sweeps delay time).
  10. Stop / start — Utility button 1, or Shift+V1 from anywhere. Stopping opens the OLED preset browser ("Sound Buffet"); a long-press of Play toggles it without stopping.
  11. Edit the sound itself — hold Shift+V4 and release to enter Voice Editing mode: the transport stops, slider buttons pick a voice, and the encoder changes the selected parameter base.
  12. Arpeggiate — hold Shift and hold V4 for 400 ms to toggle Arpeggiator mode: the pads become a scale-degree keyboard and the panel plays your chord for you. (Shift + a tap of V4 opens Voice Editing instead.)

4.2 ENV mode (a step is selected via Step Edit)

Long-press a pad to select a step. The faders then edit only that voice and that step:

FaderVoices with an envelopeStrings (no envelope)
1AttackPick hardness
2DecayT60 (ring time)
3Sustain levelPick position
4ReleaseStiffness

Hypersaw, NoiseStorm and the recipe voices use faders 1–2 for the engine controls their Attack/Decay lanes already carry (Detune / Mix, Regen / Chaos, recipe macros); faders 3–4 are their real Sustain and Release.

  • The fader position is the step's value (absolute): bottom = shortest time / zero level, top = longest / full. Values are heard the next time the step plays; a sounding note keeps its running stage, so edits never click.
  • A step you have not touched follows the patch (the preset's own envelope). The OLED shows such values in parentheses. Shift + move a fader returns that lane of the step to the patch value.
  • A fader only takes over after an obvious move (a small dead-zone of travel), so selecting a step never snaps its values to wherever the faders rest. The same applies after changing voice or leaving Step Edit, and after pressing or releasing Shift.
  • Faders never set voice bases or record live — use the encoder for bases (§6) and the distance sensor for live recording (§7).

6Magnetic Encoder (TMAG5273)

A 3D hall-effect sensor read as a rotation dial with velocity-sensitive acceleration: turn it slowly for ultra-fine single-step adjustments, quickly to sweep a whole parameter range. It edits whatever the encoder target is.

6.1 Encoder targets

Cycle targets with the UTILITY "Encoder target" button (button 6). The target order is:

Velocity → Filter → Attack → Release → Note → Octave → Slide Time → (back to Velocity)

  • Voice targets (Velocity / Filter / Attack / Release / Note) set that parameter's base value for the selected voice (its patch value). Steps that follow the patch play it; steps with their own recorded value keep theirs.
  • Note and Octave move one step per short turn; continuous targets follow turn speed.
  • Slide Time sets the portamento glide time.
  • In Step Edit mode the encoder edits the selected step's value instead: the held parameter, else the toggled edit parameter, else the encoder target's lane (named at the bottom of the OLED's ENV page). A step that follows the patch starts from the patch value. Note and Octave move one step per detent.
  • While the transport runs, a base change reaches the sounding note at once without retriggering it.
  • The OLED normally shows the playing step's composed value of the encoder target (or, while a parameter button is held, of that parameter — the value live recording writes and the voice plays). For 1.5 s after an encoder turn it shows the edited base instead, marked Base on the home screen and BASE on a parameter screen. A held parameter also shows the current lidar reading in mm.

6.2 Gate Sequence Length mode

Hold the UTILITY encoder button (about a second) to enter Gate Sequence Length mode: the LEDs show a blinking band on the selected voice's rows, and touching pads 1–16 sets that voice's Gate track length (2–16 steps). The Gate track's length is the whole pattern length for the voice (§10.2). Release the button to exit.

7Distance Sensor (VL53L1X)

A laser time-of-flight sensor with a usable range of 55–700 mm above the panel. It is the hands-free performance controller: hold (or Shift+latch) a parameter button, then move your hand over the sensor, and the reading is recorded live into that parameter's sequence at its currently playing step on the selected voice — e.g. sweep Filter over a pattern without touching anything. Hold several parameter buttons to record them all at once; each parameter records at its own track position.

  • Hand height is the value. The calibrated 55–700 mm window maps straight onto the lane's 0–1 range: near the sensor is the bottom of the parameter's range, 700 mm the top — whatever the voice's patch value. (Since 2026-09-19 these lanes store absolute values, not offsets: a base at the end of its range no longer swallows half the hand window.)
  • Continuous lanes. Velocity, Filter, Attack and Release keep recording while their step plays — the step follows your hand, and the sounding note changes without retriggering (cutoff and velocity land at once; a running attack/release keeps its length, so live edits never click).
  • Note and Octave take one value per note, on the step, so hand jitter cannot warble a sounding pitch. Pitch recording only lands while the playing gate is ON.
  • Recordable set: Note, Velocity, Filter, Attack, Octave and Release have record buttons. Decay has no record button — on many presets it is a timbre control; reach it per step with the ENV-mode faders. GateLength, Gate, Slide and Sustain are not lidar lanes.
  • Out of range pauses recording. Moving your hand out of the window (above about 740 mm, or no reading at all) pauses recording: steps keep their values instead of jumping to the minimum.
  • While a parameter button is held, the OLED parameter screen shows the sensor's current reading in mm: plain (412mm) inside the recording window, in parentheses ((812mm)) outside it, and --mm with no measurement. A held parameter's screen takes priority over the settings and sequence-length screens.
  • In Step Edit mode the sensor records into the selected step instead.
  • In Arpeggiator mode the sensor sets note dynamics instead of recording — §13.10.

10Sequencing Concepts

10.1 One sequencer per voice

Each voice has its own completely independent Sequencer instance (seq1– seq4). All four are advanced by the same uClock 16th-note tick (480 PPQN internal resolution, 120 ticks per 16th-note step, default tempo 90 BPM), but their patterns, lengths and parameters are entirely separate. This is what makes polymetry possible: Voice 1 can run a 16-step pattern while Voice 4 runs 13 steps, and they realign only every 208 steps.

10.2 Eleven parameter tracks, each with its own length

Each voice's sequencer holds eleven independent parameter tracks, one per automatable parameter, each with its own step count (default 16, settable from the pads 1–16; the core supports 2–64). Every track wraps on its own length (step modulo track length), so a 16-step Gate track with an 8-step Filter track, a 5-step Velocity track and a 3-step Octave track all run simultaneously and evolve over a common cycle.

The Gate track defines the pattern length. The sequencer's master position is clockStep modulo Gate track length, so the Gate track's step count is the whole pattern length for that voice — make it 16 for a standard bar, 13 for polymetric madness. Set it from the pads while Gate Length mode is held (§6.2), or by holding a parameter button and tapping a pad for that lane's length.

Absolute lanes and "follows the patch"

Velocity, Filter, Attack, Decay, Sustain and Release are absolute lanes: a step either holds its own 0–1 value (played as stored, whatever the patch says) or holds the follow-the-patch sentinel and plays the voice's patch/base value. Fresh, cleared and reset steps follow the patch, so an untouched pattern plays each preset exactly as designed. Note, Octave and GateLength are offsets on top of the patch (recorded scale steps add to the base note; octave adds whole octaves; gate length spreads around the patch gate length).

Slide / portamento

When a step has Slide on, the ADSR envelope is not retriggered — the pitch slews smoothly into the new note over the Slide Time set by the encoder. A gate-off step right after a slide step lets the note ring out instead of choking it.

10.3 Randomize & clear

  • Randomize (UTILITY button 7 short press, or Shift+V2) shuffles the selected voice's steps for instant variation. The rhythm is yours: gates and slides are never rewritten, and lanes whose randomize amount is 0 are left alone. Note gets fresh scale degrees (quantized into the current scale at play time), Octave and Gate Length return to their neutral midpoints, and the level/time lanes get a triangular spread — most steps hug the middle, a few wander toward the edges (default depth 35 %). The OLED confirms with RANDOMIZED + voice number.
  • Long-press Randomize (≥ 1 s) resets the selected voice's parameters instead.
  • Shift + tap clears the selected voice completely: every stored step value, all gates and slides off, all track lengths back to their 16-step defaults (CLEARED).
  • Shift + long-press clears all four voices the same way — the whole project starts fresh with no values and no gates (ALL CLEAR). Presets, tempo and transport state are kept.

10.6 Master delay

Fader 2 is a master-bus delay on the summed voice mix (both mode-switch positions; in ENV mode the faders are the selected step's envelope lanes instead, so the delay is unreachable there).

  • Wet mix — fader 2, 0 (dry) to 100 % added wet; dry stays present.
  • Delay time — Shift + fader 2: 10–750 ms on a log curve. The read head glides to the new time, so the repeats pitch-bend like a tape machine.
  • Feedback — Shift + fader 1: 0–100 %. Feedback eases over a 45 ms time constant and defaults to 85 %. At 0 % there is one delayed copy without regeneration; at 100 % the coefficient is 1.0 and the existing lowpass, DC blocker and saturation still shape the repeats. Plain fader 1 still controls tempo. This is a free-running delay, not a freeze or tempo-sync mode.
  • Not saved in the session — reboot restores mix 0, time 300 ms, feedback 85 %.

10.7 Master compressor and volume

The summed voices pass through the delay, then master volume, then the compressor. Dry sound and repeats share compression; master volume and transport mute control the whole result.

  • Master volume — fader 3; saved with the session.
  • Compressor macro — Shift + fader 3: the curve runs from Warm at 0 %, through Glue at 50 %, to Punch at 100 %. The OLED shows MACRO, its zone and percentage. The macro resets to 50 % on reboot.
  • Pressing or releasing Shift re-arms faders 1–3: move a few percent from the new resting position before either sends a value, so changing feedback leaves tempo intact, delay time leaves mix intact, and changing the compressor leaves volume intact.
  • In ENV mode, all four faders keep their selected-step envelope controls; master effects are not edited there.

11.1 The DSP chain

Each voice runs this chain at 48 kHz on the audio core. The five source engines, chosen by the preset:

  • Oscillator bank — up to 3 oscillators: band-limited B-spline saw/pulse, band-limited hard-sync saw (master/slave pair), sine, triangle, naive saw/square, or raw white noise; per-osc detune (semitones) and harmony (scale steps).
  • Waveguide — Karplus-Strong plucked string (T60 tail, brightness, pick position/hardness, stiffness, two-string detune).
  • Noise-FX texture — noise + pitch-tracked Lorenz chaos growl through a prime-tap diffuser and a regenerative allpass swarm.
  • Hypersaw — one native seven-voice detuned saw stack; detune and mix driven by the re-purposed sequencer slots.
  • Recipe engine — fixed-state modular rpdsp synthesis patches with up to three mapped timbre controls (FM, phase distortion, DSF, formant synthesis, ring modulation, reversing sync, spectral and chaotic prisms).

Filter mode (LP24, LP12, BP24, BP12, HP24, HP12) and resonance are cycled/set from the OLED Settings screen's voice-parameter page; envelope and overdrive can be switched off per voice there too. A 24 dB multi-mode ladder filter (with drive and passband gain compensation) runs on the character voices; a clean modulation-stable state-variable filter (LP/BP/HP) runs everywhere else — including all three bass presets.

11.3 The preset browser ("Sound Buffet")

  • Open it: stop the transport, or long-press Play to toggle it without stopping. Closing it: press Play (or start the transport).
  • Apply a preset: touch pads 0–28 to instantly assign that preset to the active voice. There are no pages. Pad applies are staged and click-safe while running.
  • Switch the target voice: press SliderModule V1–V4. Pads never change the voice while Settings is open.
  • Voice-parameter toggles: pressing the encoder button toggles the Settings screen between the preset browser and the voice-parameter page (envelope on/off, overdrive on/off, filter mode, filter resonance).
  • Loading a preset replaces the voice's edit bases without reseeding the sequencer lanes.

12Voice Editing Mode

Hold Shift, press V4, then release both. All four sequencers stop and audio is muted. This mode edits the actual sound — every numeric setting has a per-voice base (the patch value) that the encoder changes directly, independent of any sequenced lane.

12.1 Controls

Slider buttons 1–4 select the voice being edited (each voice remembers its parameter cursor). The button tile navigates:

Button tileAction
1 / 2Previous / next parameter group
3 / 4Previous / next parameter within the group
5, heldFine encoder adjustment
6, held 700 msReset the selected base to the loaded preset's value
7Toggle the control guide
8Exit — retaining edits and leaving the transport stopped (press Play to resume)

Groups and parameters are filtered by the active engine and enabled processors, so you only see what applies. During Voice Edit, faders, the lidar, touch pads, transport chords and the GP7 mode switch do not change the patch or sequence. A tap of Shift+V4 (without the hold) is what enters — a 400 ms hold toggles Arpeggiator mode instead (§13.2).

12.2 Patch values and step values

  • The encoder edits these requested values including outside the editor when a sequenced parameter is selected. With a step selected for editing, it edits that step's value instead. The faders never edit patch values.
  • Absolute lanes (Velocity, Filter, Attack, Decay, Sustain, Release): a step holds its own 0–1 value or follows the patch. The lidar, the encoder in Step Edit and the ENV-mode faders all write absolute values. Shift + ENV fader move, Shift+pad clear and Shift+Randomize return steps to the patch value.
  • Offset lanes (Note, Octave, GateLength) stay offsets on top of the patch: Note clamps recordedScaleStep + baseNote to 0–36, so the whole recording range writes a melody even with the default zero transpose.
  • Live edits refresh the sounding note in place — they never retrigger it. Cutoff, velocity and pitch apply at once; envelope stages land when the current stage ends or at the next note-on.
  • Randomization spreads absolute lanes around each voice's patch value and keeps randomized attacks short enough that a short gate on a sustain-0 voice stays audible.

12.3 Readouts

  • The step OLED and normal encoder screen show composed playback values — after preset bases, clamping, quantization and engine-specific mapping: the value the voice actually plays. For 1.5 s after an encoder turn they show the edited base instead (Base / BASE).
  • Note displays note names and octaves, including oscillator harmonies/detuning (Bass starts at C2/C3); unpitched percussion reads Noise. Envelope and gate durations use ms/s, cutoff uses Hz, octave uses signed octaves, FM/spacing use ratios. REST distinguishes a stored target on an inactive step from a new sounding note.
  • The preset name stays in the header while editing; * marks changes to the loaded preset. Selecting hard-sync waveforms re-maps the Velocity lane to Slave tuning; SVF offers LP/BP/HP, ladder filters offer the six native responses.

12.4 Parameter coverage

The catalogue covers sequenced bases; engine and recipe selection; oscillator count and each oscillator's waveform, level, tuning, pulse width and harmony; ADSR; main-filter topology, response, cutoff, resonance, drive, compensation and envelope amount/floor; high-pass cutoff/resonance; overdrive; glide; voice enable and output level; all waveguide, Hypersaw and Noise-FX settings; recipe macros and additional FM feedback, triangle drive, spectral sub-source ratio/shape, and Prism chaos/reset-on-gate controls. Unsupported or inactive settings are hidden. Oscillator phases, random seeds, buffer sizes and DSP callback pointers are engine implementation state, not editable patch values.

Persistence: patches persist across power cycles — every session save captures the live VoiceConfig control copy per voice, and each boot restores it. Loading a factory preset still replaces the bases; saved patches ride in the session snapshot, not the preset bank. Edits not saved with the session are lost at power-off.

13Arpeggiator Mode

Arpeggiator mode turns the whole performance surface into a chord arpeggiator. The 32 touch pads become a scale-degree keyboard, the LED panel becomes the chord map, the four faders set range / gate / swing / tone, the dial sets the rate, the distance sensor sets note dynamics, and the twelve buttons switch patterns, latch the chord and drive the transport. Hold Shift to reveal rhythm presets and four rhythm faders; Shift + dial changes tempo.

It is a mode, not a second sequencer: while it is on, the four step sequencers do not advance, and the pads neither toggle steps nor open the Step Edit pages. Everything the sequencer keeps — 4 voices, 29 presets, the scale table, the session snapshot, transport, LED themes — is shared with it. Each voice still sounds through its own patch, and Chord pattern spreads a chord over the voices.

13.1 First minute with the arp

  1. Shift + hold Voice 4 enters ARP. Release Shift.
  2. Touch three pads — for example the first, third and fifth in Major. Press Latch before lifting your fingers if you want the chord to keep going.
  3. Tap Play (or Shift + Voice 1). Turn the dial for rate; try the six pattern buttons. Voice buttons select the patch you play through.
  4. Hold Shift, then press the third pattern button for Tresillo. The strip shows three hits spaced across eight steps. Release Shift.
  5. Hold Shift and move fader 3 to slide those hits around the beat. Move fader 4 to make the first hit stand out. Shift + dial adjusts tempo.

Touch a new chord after lifting all fingers to replace a latched chord. Shift + Latch restarts the walk in either panel position. A short Play tap stops without hiding the arp screen; hold Play opens/closes the sound browser.

13.2 Entering and leaving

  • Shift + hold Voice 4 (the fourth SliderModule button) for 400 ms toggles the mode, in either direction. A tap on that same combination still opens Voice Editing mode — the press defers its action until release or hold, the same rule the Play button uses for its tap-vs-hold.
  • The OLED shows ARP ON / ARP OFF with a subtitle for 800 ms; the serial log prints [ARP] mode on plus the current settings.
  • Both edges reset the performance state: chord, latch, octave walk and step counter are dropped (settings are kept), the sequencers' note tracking is ended and all four voices are gated off, so nothing bleeds across the switch.
  • Leaving the mode restarts the sequencers if the clock is still running, so a mode flip during playback cannot leave them silent.
  • Settings survive on purpose — they describe how the player wants the arp to behave, not one performance. But the mode itself is not persisted (§13.14).

13.3 The pads are scale-degree positions

Pad index is a physical position on the 8×4 panel. For a seven-note scale, each row is one octave: columns 0–6 are the seven scale degrees and column 7 is the next octave's root. The first pad of the next row repeats the last pad of the preceding row, so the panel shows four octave rows with intentional root overlaps. For example, in Major, pad 0 is C, pads 1–6 are D–B, pad 7 is the following C, and pad 8 is that same C. Latch

Latch (Param panel bit 6, or Utility panel bit 5) keeps the notes of a chord after the fingers leave. With Latch on and nothing held, the next press starts a new chord — the classic latch gesture, so a latched chord is replaced just by playing the next one. Turning Latch off lets the latched notes go and keeps whatever is still under a finger.

13.5 Shift + pattern buttons — rhythm starting points

The OLED numbers these six buttons 1 through 6, left to right in the same order as Up, Down, Up-Dn, Rnd, Order, Chord. These choices change rhythm without changing the note pattern, chord, rate, swing or accent.

A tap selects the voice the arp plays through — the same direct voice select as the sequencer uses, so the arp inherits whatever patch that voice holds. Shift + tap gives the transport chords (Play/Stop, Randomize voice, Scale), and Shift + hold Voice 4 toggles the mode.

13.9 Encoder (TMAG5273)

Turn = rate: 1/4, 1/4T, 1/8, 1/8T, 1/16, 1/16T, 1/32, 1/32T — one detent per division. Slow turns accumulate until a detent is reached, and reversing direction answers immediately instead of unwinding motion from the other way. The TMAG5273 board has no switch on this rig, so the mode uses the dial only; re-sync lives on Shift + Latch in either panel position.

Shift + turn = tempo, 45–200 BPM, in one-BPM detents. Motion left over from Rate never carries into Tempo or back. The voice editor keeps ownership of the dial when open.

13.10 Distance sensor — dynamics

Hand height inside the 55–700 mm window scales the velocity of every note the arp starts: from a quarter of the patch's velocity with the hand close to the sensor, up to the full patch value with the hand raised. With no hand in range nothing is attenuated, so a chord left alone sounds as the preset was designed. The LED panel brightens each sounding note using its captured dynamics and accent together. Moving the hand changes subsequent notes.

In this mode the sensor never records into steps — there are no steps to write.

The 128×64 play page uses eight fixed rows, with no scrolling or auto paging. Holding Shift reveals the six rhythm choices (Param panel), the Shift-fader assignments and the tempo-dial hint; the Utility side shows Restart/Clear instead. On-screen button numbers are one-based; the hardware tables above use zero-based bits. Control feedback replaces only the middle three rows.

13.13 Under the hood (for the curious)

  • The arp is driven by uClock's 480 PPQN output-pulse ticks — the same counter the sequencer drains for note-offs — so every rate lines up with the transport grid instead of drifting against it. Swing delays every second gap and shortens its partner by the same amount, so a pair still lasts two intervals and no drift accumulates.
  • The engine reports note starts/stops by slot (0–3); slot 0 maps to the selected voice and slots 1–3 to the remaining voices in index order, so Chord pattern sounds on up to four different patches. The slot→voice memory survives voice changes until each gate closes.
  • Notes start from each patch's own base: engine, envelope and levels come from the voice's patch; the arp overrides only pitch, its octave of range, the dynamics velocity and the filter fader. Envelope retrigger uses the same event the step sequencer publishes — no DSP path is special-cased.
  • Hard rules: a release always reaches the chord (modal states that swallow edges call releaseAllHeldPads(), which drops held pads and keeps latched ones); a gate always stops before the next note on the same tick, so a mono pattern retriggers from silence instead of gliding; an empty chord leaves rests, not a rhythm that stops and restarts out of time.

13.14 Defaults & persistence

The mode and its settings are runtime state. The session snapshot is untouched, so a power cycle boots into the step sequencer with the arp at its defaults: Up pattern, 1/16 rate, 1 octave, 50 % gate, no swing, filter 0.5, rhythm All 8/8, rotation 0, accent off. Session load/save in this mode still saves and restores the session — voices, presets and patterns — it just does not carry the arp.
Checking it on hardware: host tests prove the logic; they cannot prove the sound. Bench-check a held chord against the transport, rate changes while running, latch on/off, Chord pattern across four voices, the lidar dynamics, and that leaving the mode returns the pads and the sequencer intact.

14Sessions & Persistence

  • Save: UTILITY button 2 tap writes everything to flash; the transport pauses ~0.5 s for the write, then resumes. OLED: SAVED.
  • Load: button 2 long-press (≥ 0.4 s) reloads the last saved session. OLED: LOADED / LOAD ERR.
  • Autosave: edits are also saved automatically about a second after you press Stop (only if something changed).
  • Watchdog recovery: after a watchdog freeze the unit restores the live session by itself — no power-cycle needed.

14.1 What gets saved

  • All four voices' patterns — every parameter lane, including polymetric lengths.
  • Each voice's patch: preset + all Voice Edit adjustments (the live VoiceConfig control copy).
  • Tempo, master volume, scale, shuffle template, LED theme, selected voice, and the recorded encoder-modifier state.

14.2 What is not saved

  • Delay controls — reboot restores mix 0, time 300 ms, feedback 85 %.
  • Compressor macro — resets to 50 % on reboot.
  • Arpeggiator mode and its settings — the arp is runtime state (§13.14).

Everything you program survives power-off.

15Connectivity & Clock

15.1 No MIDI

Pico2Seq does not transmit or receive any MIDI. The USB port enumerates as a CDC serial device (Adafruit TinyUSB stack) and carries power plus the 115200-baud diagnostics console only. There is no CC output, no MIDI clock, and no MIDI-in feature.

15.2 Clock & timing internals

uClock runs at 480 PPQN (120 ticks per 16th-note step); each 16th note advances all four sequencers, ticks gate timers and drives the internal note lifecycle. Default tempo 90 BPM, range 45–200. The uClock timer ISR fires on core 0 (the control core), which is why audio synthesis lives entirely on core 1.

15.3 Dual-core split

Core 0 — controlCore 1 — audio
1 ms sensor poll (encoder, lidar) · MPR121 32-pad scan · Alchemy tile polling (I²C1) · 50 Hz OLED & LED updates · uClock step ticking & PPQN gate drains · USB CDC console 48 kHz VoiceManager::processBlock() · 4-voice synthesis chain · FloatToPcm16() · non-blocking I2S DMA. Never allocates heap, never blocks on I²C, never touches USB.

Core 0 stages parameter changes through atomic generation counters and lock-free SPSC queues, so the audio core never sees a half-written config.

15.4 Gate I/O

There is no hardware gate input or output in the current firmware, and with USB MIDI gone there is no built-in way to gate external gear. The panel's "Gate Input" label is a leftover from the hardware design [unverified].

16Troubleshooting & Gotchas

16.1 Behavioral gotchas (by design, verified in code)

SymptomExplanation
Can't program a pitch into a stepNote edits (sensor, encoder step edit) are rejected on gate-off steps. Toggle the step on first.
Lidar or fader seems to record nowhereThe OLED ENV page (Attack/Decay/Sustain/Release rows) means a step is in Step Edit, so recording goes to that step only. Long-press the same pad again (or tap any pad) to leave Step Edit.
Pad does something unexpectedCheck the context: a held parameter button turns pad presses into track-length setting; Gate Length mode turns them into Gate length; Shift turns them into clear-step. All pads are step pads — there is no pad "menu".
Stopping the transport opens the preset browserIntentional (and a Play long-press toggles it without stopping). Press Play to leave it.

A voice goes silent on some stepsCheck those steps' Attack and Decay on the ENV page. A voice with sustain 0 (Square, Percussion) ends at the attack peak, so a very short decay or an attack longer than the gate barely sounds. Shift + move the fader to return the lane to the patch value.
Fader "jumps" when it takes overAfter a mode flip, voice change, Shift edge, or entering/leaving Step Edit, a fader does nothing until it moves a small dead-zone of travel; the value then jumps to where the fader is.

Voice numbers look offThe OLED shows 0-based Voice: 0–Voice: 3; the voice buttons and this manual say V1–V4 for the same voices.
Arp settings vanished after power cycleBy design: the arp is runtime state and boots at its defaults (§13.14). Sessions save/load the step-sequencer session only.
