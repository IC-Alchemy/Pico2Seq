§ 1 Panel & Hardware Layout

Pico2Seq features a dual-surface control architecture pairing dedicated physical step pads with modular parameter/utility controls:

  • 32 Capacitive Touch Pads (MPR121 @ 0x5A): Dedicated exclusively as step pads, split into two 16-step banks representing the currently active voice pair (V1/V2 or V3/V4).
  • 8×4 WS2812B RGB LED Matrix (GPIO 1): Directly mirrors the touch pad grid 1:1, rendering active gates, beat playhead accents, breathing idle wave, and polyrhythmic overlays.
  • SliderModule (4 Faders + 4 Voice Buttons): 12-bit ADC continuous control and direct selection for Voices 1–4.
  • ButtonModule8 (8 Tactile Buttons + GP7 Mode Switch): Dual function sets for Param Mode (Note, Velocity, Filter, Attack, Decay, Octave, Slide, Shift) and Utility Mode (Play/Stop, Delay, Scale, Swing, Theme, Encoder Target, Randomize, Shift).
  • TMAG5273 Magnetic Encoder (I2C 0x35): Velocity-sensitive 3D hall-effect knob for precision parameter tweaking and gate length adjustments.
  • VL53L1X Time-of-Flight Laser Sensor (I2C 0x29): Hands-free performance modulation over 74–1400 mm.
  • OLED Display (SH1106G 128×64 @ 0x3C): Deterministic 5-tier priority rendering system.

§ 2 Quick Start Tutorial

  1. Power & Audio: Connect Stereo Out (3.5mm) to mixer/headphones and supply USB-C power. The transport boots running at 90 BPM.
  2. Factory Presets: Boots with Voice 1 = Square, Voice 2 = Bass, Voice 3 = Digital, Voice 4 = Percussion.
  3. Inputting Notes: Tap pads in Bank 0 (Low Voice) or Bank 1 (High Voice) to toggle step gates.
  4. Tweak Sound: With GP7 mode switch set to PARAM, move Faders 1–4 to modulate Filter, Attack, Decay, and Velocity.
  5. Polymeter: Hold a parameter button (e.g. Filter) and tap Pad 5. The filter track now cycles every 5 steps against the 16-step gate track!

§ 5 Complete Control Reference

Param Mode (GP7 LOW)
  • • Hold Param Button: Arms real-time recording via encoder/sensor.
  • • Shift + Param Tap: Latches hold without finger contact.
  • • Fader 1–4: Filter Cutoff, Attack, Decay, Velocity.
Utility Mode (GP7 HIGH)
  • • Btn 1 (Play/Stop): Starts/stops transport; opens Settings when stopped.
  • • Btn 2 (Delay): Toggle the delay state/notice (the delay insert is commented out of the firmware audio path, so no delay is audible).
  • • Btn 3 (Scale): Cycle 13 musical scales.
  • • Btn 4 (Swing): Cycle 16 shuffle templates.
  • • Btn 5 (Theme): Cycle 10 LED matrix color themes.
  • • Btn 6 (Target): Cycle encoder target (hold = Gate Length mode).
  • • Btn 7 (Random): Short tap randomizes voice; long-press resets.

⚠️ Hardware & Firmware Gotchas Reference

Critical behavioral nuances verified directly from C++ firmware source.

⚡ Voices 3 & 4 Are Internal-Audio Only

Only Voices 1 and 2 have USB MIDI note/gate output and gate timers wired. Voices 3 and 4 are synthesis-only and do not emit external MIDI notes.

⚡ Encoder Offsets Apply to Voices 1 & 2 Only

applyEncoderBaseValues() is invoked only for internal voices 0 and 1. Turning the encoder while Voice 3 or 4 is selected will not alter step offsets.

🔒 Note Edits Are Gate-Protected

You cannot write or record a pitch into a step whose Gate is OFF. Toggle the step ON first before setting pitch via encoder, distance sensor, or faders.

🎚️ Fader Value Snapping on Mode Flip

When flipping the GP7 mode switch between PARAM and UTILITY, the physical slider positions snap into the new parameters upon the first reading.

📏 VL53L1X Distance Window (74–1400 mm)

Readings below 74 mm or above 1400 mm return invalid (-1) and are ignored by firmware. Distance is normalized from 74 mm upwards.

🎛️ Staged Parameter Updates

Voice parameter updates cross Core 1 to Core 0 via atomic staging (stagedState_) and take effect on the next audio buffer slice.
