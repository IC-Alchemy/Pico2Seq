01How a Pico2Seq voice is built

Every preset — whatever engine it uses — flows through the same shared chain. The engine only replaces the source stage; everything after it is common, which is why a patch is fully described by its source plus a handful of chain settings. Since the drone build the per-voice main filter and amplitude envelope are gone from the audio path entirely: sources render continuously, gate-off does not silence them (they keep sounding at the last committed pitch), and a gate rise only re-triggers the engines (waveguide pluck, Hypersaw phase randomize, recipe reset) and commits pitch.

Sequencer lanes: Note, Velocity, Filter, Attack, Decay, Octave, Gate-Length, Slide and Gate are the nine recorded tracks. Filter / Attack / Decay are macro-only: each preset either binds them to engine macros or leaves them inert (the OLED shows "--"). WAVEGUIDE binds Brightness / Pick / T60; every recipe patch defines its own three named macro lanes (color / shape / character); HYPERSAW binds Detune / Mix and leaves the Filter lane inert; NOISESTORM binds swarm Color / Regen / Lorenz Chaos; HARDSYNC renames Note / Velocity to Master / Slave — Velocity becomes the sync slave ratio (±24 st) — and leaves Filter / Attack / Decay inert. The nine oscillator presets (Analog … RubberSub) have no filter, envelope or cutoff spans at all: their Filter / Attack / Decay lanes are unbound and inert. Only there does Velocity still scale amplitude; waveguide spends it on pluck energy instead. Note, Octave, Gate-Length, Slide and Gate always keep their shared meanings.
